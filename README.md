# Reps

A progression framework. Each rep builds on the last, adds exactly one new
challenge, and gets harder *because* the previous level is mastered — not
because more is piled on.

## Rep 1: [Foundation]

**Builds on**: Nothing — this is the starting point
**New challenge**: The core move, done cleanly end to end
**Expected difficulty**: Baseline (this sets the bar every later rep is measured against)

## Rep 2: [Next level]

**Builds on**: What you learned in Rep 1
**New challenge**: One new thing to try or improve
**Expected difficulty**: Harder (because you've mastered Rep 1)

## Rep 3: [Continue progression]

**Builds on**: Reps 1–2
**New challenge**: [...]

## Reps 4–5: Future Path

(Details evolve based on what you actually learn in Reps 1–3)

## Rules of the ladder

- One new challenge per rep — never two.
- A rep counts only once the previous one is mastered.
- Reps 4–5 are never planned in advance. They are written from what
  Reps 1–3 actually taught.
